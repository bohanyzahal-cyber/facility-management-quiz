## תכונות

- **מצב תרגול** — משוב מיידי והסבר מנומק אחרי כל שאלה, ותרגול חוזר של השגויות בלבד. אורך הסבב נבחר (20 / 40 / הכל, ברירת המחדל 20) — הכפתור לתרגול השגויות מופיע רק במסך שבסוף הסבב, ולכן סבב קצר הופך אותו לשמיש. גם כאן הדגימה מאוזנת בין הנושאים.
- **סימולציית מבחן** — 20 / 30 / כל השאלות, שעון אופציונלי (30/45/60 דק'), מפת שאלות למעבר מהיר, הגשה וציון, וסקירה מלאה של כל שגיאה עם התשובה הנכונה וההסבר.
- **פריסה מאוזנת בין נושאים** (פעילה כברירת מחדל) — המאגר אינו מאוזן, ולנושא העשיר ביותר יש פי-3 שאלות מהדל ביותר. הפער אינו משקף את משקל הנושאים במבחן אלא את היקף החומר שנמצא עליהם, ולכן דגימה אקראית מרכזת את המבחן בשניים-שלושה נושאים ומחמיצה אחרים. הפריסה המאוזנת לוקחת לסירוגין מכל נושא ומכסה את כל ה-13. ניתן לכבות.
- **ערבוב תשובות בכל סבב** — סדר האפשרויות מתערבב מחדש בכל הרצה, כך שאי אפשר לזכור מיקומים.
- סינון לפי נושא ולפי מקור · מונה נכונות/שגויות ואחוז הצלחה · מצב כהה/בהיר · מותאם למובייל.
- קובץ יחיד ועצמאי, ללא תלויות חיצוניות.

## בנייה מחדש

השאלות אינן נערכות ישירות ב-`index.html` אלא במקורות:

```bash
cd src && python build.py
```

`build.py` משבץ את `bank*.js` לתוך `template.html` וכותב את `index.html`. הסכמה של כל שאלה:

```js
{t:"נושא", s:"מקור", q:"השאלה", o:["א","ב","ג","ד"], c:1, e:"הסבר"}
```

`c` הוא אינדקס התשובה הנכונה **לפני** הערבוב. מכיוון שהאפליקציה מערבבת את סדר האפשרויות, **אין לכתוב מסיחים תלויי-מיקום** ("כל התשובות נכונות", "תשובות א'+ב'"). הסקריפט מדפיס את פיזור התשובות ככלי בקרה.
