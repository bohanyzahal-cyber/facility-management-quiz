# פודקאסט — ניהול תשתיות גלובליות

13 פרקים, פרק לכל נושא, סה״כ ~4 שעות. נבנה מאותו חומר של החוברת
(`../exam/content.js`) ובנק השאלות, כדי שהכל יאמר את אותו דבר.

## מה יש כאן

| | |
|---|---|
| `mp3/` | קבצי השמע. **זה מה שמעתיקים לטלפון.** |
| `index.html` | דף נגן — לחיצה מפעילה פרק בדפדפן. נבנה אוטומטית. |
| `scripts/` | התסריטים. זה מה שעורכים כשרוצים לשנות תוכן. |
| `build.py` | ממיר תסריט לקובץ שמע. |

## בנייה

```
cd podcast && python build.py          # רק מה שהשתנה
python build.py 07                     # פרק בודד
python build.py --force                # הכל מחדש
```

דורש `edge-tts` (מותקן) ו-`ffmpeg` (ב-PATH). הסינתזה מקוונת — צריך אינטרנט.

כל שורה מסונתזת בנפרד ונשמרת ב-`.cache/` לפי גיבוב של הטקסט והקול, כך ששינוי
משפט אחד בונה מחדש שורה אחת ולא פרק שלם. `index.html` נכתב מחדש רק בבנייה
מלאה (בלי ארגומנט של פרק), אחרת הוא היה נחתך לפרקים שנבנו.

## פורמט התסריט

```
# title: שם הפרק                 <- קובע את שם הקובץ ואת תגית ה-ID3
ש: שורה של המראיינת              <- קול נשי (Hila)
א: שורה של המרצה                 <- קול גברי (Avri)
~4                               <- שקט של 4 שניות (זמן לחשוב על שאלה)
                                 <- שורה ריקה = הפסקה של 0.9 שניות
# הערה                           <- לא נקרא
```

## החלטות שכדאי לדעת עליהן לפני שמשנים

**ראשי תיבות נכתבים בתעתיק עברי** — `אס אל איי`, לא `SLA`. הקול ההברתי
מבטא גם אותיות לטיניות, אבל התעתיק נותן את ההגייה שאומרים בכיתה. **מספרים,
לעומת זאת, נכתבים בספרות** — המנוע מרחיב אותם נכון (נבדק: `85%` יוצא באורך
זהה ל„שמונים וחמישה אחוז״). למספרים מורכבים בכל זאת נכתבה מילה מלאה, כי כך
קל יותר לקרוא את התסריט.

**שני קולות ולא אחד.** מונולוג באורך 20 דקות מאבד את המאזין; חילופי דובר
מחזיקים קשב, ומבנה של שאלה-תשובה מתרגל שליפה ולא רק זיהוי.

**„שאלות לדרך״ בסוף כל פרק** — 5 שאלות, כל אחת עם `~4` לפני התשובה. זה החלק
היחיד שאי אפשר לקבל מהחוברת בזמן נהיגה, ולכן הוא הסיבה שהפודקאסט לא מיותר.

**פרק 13 בנוי אחרת** — הוא תרגול רצוף של ראשי תיבות ומספרים, בלי הסברים,
מיועד להאזנה חוזרת.

**מספרים סותרים נאמרים בקול כשניהם.** היכן שההרצאה והמקראה נתנו מספר שונה
(שכר ב-FM, פחת על בניין, גובה גורד שחקים, ROI) הפרק אומר במפורש ששניהם
הופיעו, במקום לבחור אחד ולהסתכן.
